## Goal
Cut the renderer's transient native memory (canvas rebuffers at 2x DPR) and paint frequency
so a dev-mode tab stays under ~300MB peak for hours. Implement the ADR's five layers:

1. Shared rAF loop with per-panel-class fps caps (kline 5, ladder 10, tape 5, bookstrip 10).
   Implement as a small `createRenderBudget()` utility (src/lib/render/budget.ts) with:
   - `markDirty(id)` — data-ready flag per panel id
   - `register(id, {fps})`
   - each rAF tick: paint panels whose dirty && now-lastPaint >= 1000/fps
   - expose `paintedLastSecond` for the DEV PERF panel
   Wire CandleChart/TradeTape/ladder paint into it (each panel keeps its own canvas but the
   DECISION to repaint goes through the budget — do NOT merge into a single canvas in this pass).
   For lightweight-charts panels, throttle `series.update`/`setData` calls through the budget
   (chart's own rendering only happens on update, so throttling updates = throttling paint).
2. IntersectionObserver gating: hook `useInViewport(ref)` (src/hooks/useInViewport.ts);
   panels skip paint (and skip chart updates) when not intersecting.
3. DPR cap: when sizing canvas backing stores use Math.min(devicePixelRatio, 1.5); if a
   "low memory" toggle (localStorage key trading-ui.low-memory === '1') then DPR = 1.
   Put a small toggle in the header near the Market/Stream pills rendering that key.
   Also gate DEV PERF overlay behind `?perf=1` OR (import.meta.env.DEV && low-memory off),
   and drop its update rate to 1 Hz.
4. Tape: max 30 visible rows, update text nodes in place via keyed reuse (no full rebuild).
5. Backpressure shed: in useBinanceMarket flush(), measure rAF gap; if >500ms, drop all but
   the latest pending depth snapshot per pair, coalesce kline merges, cap pending trades
   merge at PENDING_TRADES_FLUSH_NOW (already exists) and add a hard cap 800 for the shed case.
